# SCT HelpChain Digital Exchange & Payment Gateway
Sovereign Web3 Donation Core Protocol Under 102740

## Overview
This repository hosts the secure, decentralized digital exchange interface and payment gateway components for **SCT HelpChain International**. It operates strictly as a backend support system to process transparent crypto-fiat conversions (BNB Smart Chain) for our primary charitable network.

## Core Assets
- **Indx.html**: Main exchange layout.
- **Web/**: Core JavaScript modules for MetaMask integration.

*All transaction modules are fully open-source and optimized for low-spec humanitarian testing loops.*
